# YouTube 模糊背景

瀏覽器外掛（Chrome / Edge / Firefox，Manifest V3）：在 YouTube 觀看頁，把正在播放的影片即時做高斯模糊，
鋪滿整個網頁原本的黑底（深色主題）或白底（淺色主題），連播放器內的上下／左右黑邊與全螢幕黑邊也一起填滿。

## 安裝

**Chrome / Edge**

1. 開啟 `chrome://extensions`（Edge 為 `edge://extensions`）
2. 打開右上角「開發人員模式」
3. 按「載入未封裝項目」，選擇這個 `yt-blur-backdrop` 資料夾

**Firefox**

1. 開啟 `about:debugging#/runtime/this-firefox`
2. 按「載入臨時附加元件」，選擇資料夾裡的 `manifest.json`（臨時載入，重開瀏覽器後需再載一次）

## 設定

點工具列上的外掛圖示即可調整，修改會立即套用到已開啟的分頁：

| 項目 | 說明 |
| --- | --- |
| 啟用 | 總開關 |
| 播放器黑邊也填滿 | 影片比例與播放器不同（例如直式影片、21:9 電影）時，黑邊也換成模糊畫面，全螢幕同樣有效 |
| 模糊程度 | 模糊半徑，數值越大越朦朧 |
| 遮罩濃度 | 深色主題疊黑、淺色主題疊白，確保標題、留言等文字看得清楚 |
| 飽和度 | 讓模糊後的顏色更鮮豔或更淡 |
| 更新頻率 | 背景每秒重畫幾次；調低可省電 |

## 原理

- 每一格把 `<video>` 以 `object-fit: cover` 的方式畫到一張 160 px 寬的小 canvas，再用 CSS `filter: blur()`
  放大到整個視窗。模糊後本來就看不到細節，小解析度幾乎不耗效能；暫停或分頁在背景時不重畫。
- 背景層固定在頁面最底層（`z-index: -1`），再把 YouTube 的實心底色（`--yt-spec-base-background` 與各容器背景）
  改成透明讓它透出來；頂部標題列改為毛玻璃。
- 進入全螢幕時背景層會搬進全螢幕元素內，才能出現在播放器黑邊。
- 只在 `/watch` 頁啟用；YouTube 內建的「劇院燈光（Ambient mode）」會被暫時隱藏以免重疊。

## 限制

- 有 DRM 保護的內容（付費電影等）瀏覽器不允許讀取畫面，背景會是黑的。
- YouTube 改版調整元素名稱時，部分區塊可能會恢復實心底色，需要更新 `content.css` 的選擇器。
