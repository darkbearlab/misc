# STL 列印預覽排版器

單一 HTML 檔，用瀏覽器打開就能用：把多個 STL 同時放到虛擬列印床上，
各自獨立移動、旋轉、翻轉，用來預覽組裝效果、決定這一盤要送哪些檔案去列印。

打開方式：直接用瀏覽器開啟 [`index.html`](index.html)（雙擊即可，不需要伺服器、不需要網路）。
檔案完全不會離開你的電腦。

## 功能

- **多檔同場** — 拖曳或選取多個 STL 一次匯入，自動找空位擺放，不會疊在一起
- **個別操控** — 每個模型獨立移動、繞 X/Y/Z 轉 90°（或自訂角度）、鏡射翻轉、縮放
- **組裝預覽** — 關掉「旋轉後自動貼底」就能把零件懸空疊起來，檢查拼合效果
- **列印床範圍檢查** — 內建常見機型尺寸（Bambu / Ender / Prusa…）或自訂，超出範圍的模型會標紅並跳警告
- **列印清單** — 每個模型有勾選框，未勾選的顯示為半透明；側欄即時統計件數、體積與 PLA 實心估重
- **匯出** — 「複製清單」把選定項目貼到別處；「匯出整盤 STL」把目前的擺位合併成一個 STL 丟進切片軟體

## 操作

| 動作 | 按鍵 |
| --- | --- |
| 在床面移動模型 | 左鍵拖曳模型 |
| 調整高度 | `Shift` + 拖曳 |
| 旋轉視角 | 在空白處左鍵拖曳 |
| 平移視角 | 右鍵 / 中鍵拖曳 |
| 縮放視角 | 滾輪 |
| 繞 X/Y/Z 轉 90° | `X` `Y` `Z`（加 `Shift` 反向） |
| 鏡射 | `M` |
| 複製一份 | `D` |
| 對焦選取的模型 | `F` |
| 刪除 | `Del` |
| 取消選取 | `Esc` |

## 實作

零依賴：STL 解析（二進位與 ASCII）、矩陣運算、WebGL 渲染、滑鼠拾取（CPU 上的
Möller–Trumbore 射線與三角形相交）全部寫在這個檔案裡，所以離線也能用，
不會因為 CDN 掛掉而失效。

座標系採 3D 列印慣例：Z 軸向上，床面在 `z = 0`，範圍 `[0,W] × [0,D]`。
物件的旋轉存成 3×3 基底矩陣而非歐拉角，鏡射就是行列式為負的基底，
所以旋轉與翻轉可以任意組合而不會有萬向鎖或順序問題；匯出時偵測到負行列式
會自動交換頂點順序，法線才會朝外。
